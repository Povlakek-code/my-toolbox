## ✨ 项目简介

**All-in-One Toolbox & Mini Games** 是一个轻量、现代、纯静态的在线工具与小游戏合集项目。

项目将常用开发工具、文本处理工具、图片颜色工具、日常效率工具以及经典小游戏整合在同一个入口页面中。整体采用原生 HTML、CSS、JavaScript 实现，适合直接部署到 GitHub Pages、Cloudflare Pages、Vercel、Netlify 等任意静态托管平台。

项目核心目标：

- ✅ 打开即用
- ✅ 无需登录
- ✅ 无需服务器
- ✅ 无需数据库
- ✅ 数据尽量本地处理
- ✅ 适合 GitHub Pages 免费部署
- ✅ 适合个人长期维护和扩展

## 🌟 项目特性

### 1. 纯静态架构

整个项目可以直接作为静态站点运行：

* 不依赖后端服务
* 不依赖数据库
* 不需要 Node.js 构建
* 不需要 npm install
* 不需要服务器部署经验

只要浏览器能打开 HTML 文件，即可运行。

***

### 2. GitHub Pages 友好

项目天然适合 GitHub Pages：

* 根目录入口为 `index.html`
* 子页面使用相对路径跳转
* 资源结构简单清晰
* 适合个人仓库、组织仓库或项目页部署

***

### 3. 本地优先与隐私友好

大部分工具逻辑均在浏览器本地完成，例如：

* 文本处理
* JSON 格式化
* Base64 编解码
* 图片压缩
* 颜色转换
* 密码生成
* UUID 生成
* 游戏运行

项目设计原则是：

> 能在本地处理的，就不上传到服务器。

***

### 4. 统一入口与搜索分类

首页 `index.html` 提供统一导航入口，支持：

* 工具分类
* 游戏分类
* 关键词搜索
* 卡片式布局
* 响应式展示
* 移动端适配

适合在工具数量持续增长后保持良好的可维护性和使用体验。

## 🌐 部署到 GitHub Pages

### 1. 创建仓库

在 GitHub 创建一个新仓库，例如：

```text
all-in-one-toolbox
```

***

### 2. 上传项目文件

确保目录结构类似：

```text
index.html
README.md
tools/
games/
```

***

### 3. 开启 GitHub Pages

进入仓库：

```text
Settings → Pages
```

选择：

```text
Source: Deploy from a branch
Branch: main
Folder: /root
```

保存后等待 GitHub 自动部署。

***

### 4. 访问网站

部署完成后，访问：

```text
https://你的用户名.github.io/仓库名/
```

## 🔒 隐私说明

本项目的核心原则是：

> 用户数据尽量只在浏览器本地处理。

除非某些页面主动引入第三方 CDN 库，否则项目本身不需要：

* 用户注册
* 用户登录
* Cookie 存储
* 后端接口
* 数据上传
* 行为追踪

如果你希望进一步增强隐私性，可以将所有第三方 CDN 资源下载到本地，并改成本地引用。

***

## ⚡ 性能建议

为了让项目在工具数量继续增加后仍然保持优秀体验，建议：

* 将公共样式抽离为 `assets/css/style.css`
* 将首页卡片数据抽离为 `assets/js/items.js`
* 将公共返回首页按钮抽成统一组件
* 避免每个页面重复写大量相同 CSS
* 图片资源尽量压缩后再提交
* 避免引入过重的第三方库

推荐未来目录：

```text
.
├── index.html
├── README.md
├── assets/
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   ├── common.js
│   │   └── items.js
│   └── images/
├── tools/
└── games/
```
